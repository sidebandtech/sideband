# @sideband/transport-browser

Browser transport for Sideband.

> **Not yet implemented.** This package is a placeholder for the planned browser WebSocket transport.

## Planned Features

- WebSocket-based `Transport` implementation for browsers
- Automatic reconnection with exponential backoff
- Error recovery and connection state management
- Works in modern browsers and ServiceWorkers

## Install

```bash
bun add @sideband/transport-browser
```

Will implement the `Transport` interface from [`@sideband/transport`](https://www.npmjs.com/package/@sideband/transport). For Node.js/Bun environments, see [`@sideband/transport-node`](https://www.npmjs.com/package/@sideband/transport-node).
