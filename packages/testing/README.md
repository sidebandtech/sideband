# @sideband/testing

Shared test helpers for Sideband.

> **Not yet implemented.** This package is a placeholder for planned test utilities.

For development use only. Do not import in production code.

## Planned Features

- Peer fixtures and mocks
- Frame generators for test scenarios
- Shared test utilities for runtime and transport packages

For the in-memory transport used in tests, see `MemoryTransport` in [`@sideband/transport`](https://www.npmjs.com/package/@sideband/transport).

## Install

```bash
bun add -D @sideband/testing
```
