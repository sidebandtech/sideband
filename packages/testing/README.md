# @sideband/testing

Shared test helpers for Sideband. For development use only — do not import in production code.

> **Not yet implemented.** This package is a placeholder for planned test utilities.

## Planned features

- Peer fixtures and mocks
- Frame generators for test scenarios
- Shared test utilities for runtime and transport packages

For the loopback transport used in current tests, see `LoopbackTransport` in [`@sideband/transport`](https://www.npmjs.com/package/@sideband/transport).
